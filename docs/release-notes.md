首个可分享版本：把源代码整理成可点击的离线 HTML 工作流。

- 共同步骤合并，分支清楚，点节点展开输入、处理与输出。
- 源码摘录保留版本、行号和指纹，支持原文 / 中文注释切换。
- 展示提示词模板、参数与明确标记的示例；支持固定基线对比。
- SVG 导出、打印、键盘选择、手机局部滚动。
- Python 标准库生成 HTML；阅读结果不需要服务器或第三方资源。
